# เว็บค้นหาข้อมูลจาก Google Sheet (หลายไฟล์)

โครงสร้างโปรเจกต์:

```
sheet-search/
├── backend/
│   └── Code.gs        # Apps Script โปรเจกต์แยกต่างหาก (standalone) — รู้จักหลายไฟล์ผ่าน SPREADSHEETS
└── frontend/
    ├── index.html      # หน้าเว็บหลัก (เลือกไฟล์ → เลือกแท็บ → ดู/เพิ่ม/ลบข้อมูล)
    ├── style.css       # ดีไซน์
    ├── script.js       # เรียก API และแสดงผลลัพธ์
    └── config.js       # ใส่ URL ของ API และรหัสเข้าถึง
```

## ภาพรวมสถาปัตยกรรม

GitHub Pages โฮสต์ได้เฉพาะไฟล์ static (HTML/CSS/JS) จึงรัน Google Apps Script บนนั้นไม่ได้โดยตรง
วิธีที่ใช้งานได้คือแยกสองส่วน:

1. **Backend** — Apps Script โปรเจกต์แยกต่างหาก (ไม่ผูกกับไฟล์ Sheet) เปิดไฟล์ตามรายการใน `SPREADSHEETS` ด้วย `SpreadsheetApp.openById()` deploy เป็น Web App จะได้ URL สำหรับเรียกแบบ API
2. **Frontend** — ไฟล์ static ใน `frontend/` วางบน GitHub Pages แล้วเรียก URL จากข้อ 1 ผ่านเทคนิค JSONP (ไม่ใช้ `fetch()` เพราะ Apps Script ไม่ส่ง CORS header กลับมา)

**เรื่องสิทธิ์การเข้าถึง:** ใช้ **รหัสเข้าถึงแบบรหัสลับ (access key)** แทนการล็อกอินด้วย Google เพราะการล็อกอินทำให้เกิดปัญหา CORS/redirect เมื่อเรียกข้ามโดเมน

## หน้าตาการใช้งาน (3 ขั้น)

1. **เลือกไฟล์** — หน้าแรกโชว์การ์ดรายชื่อไฟล์ทั้งหมด โหลดเร็วเพราะไม่แตะเนื้อหาในชีตเลย มีปุ่ม **"+ เพิ่มไฟล์ใหม่"** ให้เพิ่มไฟล์ Google Sheet เข้าระบบได้เองจากหน้าเว็บโดยตรง (วางชื่อที่อยากให้แสดง + ลิงก์ไฟล์) โดยไม่ต้องแก้โค้ดหรือ Deploy ใหม่เลย — เพิ่มเสร็จใช้งานได้ทันที และกด × ที่มุมการ์ดเพื่อเอาไฟล์ออกจากระบบได้เช่นกัน (ไม่ได้ลบไฟล์ Google Sheet จริง)
2. **เลือกแท็บ** — กดเข้าไฟล์แล้วเห็นทุกแท็บในไฟล์นั้นเป็นปุ่มให้เลือก
3. **ดู/เพิ่ม/ลบข้อมูล** — เลือกแท็บแล้วค้นหาได้ตามปกติ พร้อมปุ่ม "+ เพิ่มข้อมูล" และ "จัดการคอลัมน์" (ลบทั้งคอลัมน์) และปุ่มถังขยะที่แต่ละการ์ดผลลัพธ์ (ลบทั้งแถว) ทุกการลบมีระบบถังขยะให้กู้คืนได้ผ่านปุ่ม "🗑 ถังขยะ"

## ขั้นตอนที่ 1: ตั้งค่า Backend (Apps Script)

1. ไปที่ **script.google.com** → กด **New project**
2. ลบโค้ดตัวอย่างเดิมออกให้หมด (รวมถึงบรรทัด `function myFunction() {}`) แล้ววางโค้ดจาก `backend/Code.gs` แทน
3. รายชื่อไฟล์ตอนนี้เก็บอยู่ใน **Script Properties** ไม่ใช่โค้ดอีกต่อไป (ดูข้อ 4) — ค่า `DEFAULT_SPREADSHEETS` ในโค้ดจะถูกใช้แค่ครั้งแรกที่รันเท่านั้น เพิ่มไฟล์ใหม่ทีหลังทำผ่านปุ่ม "+ เพิ่มไฟล์ใหม่" บนหน้าเว็บได้เลย ไม่ต้องแก้ตรงนี้อีก
4. ไปที่ **Project Settings** (ไอคอนรูปเฟือง) → **Script Properties** → เพิ่ม property ชื่อ `DASHBOARD_ACCESS_KEY` ค่าเป็นรหัสลับที่ตั้งเอง
5. กด **Deploy > New deployment**
   - เลือกประเภท **Web app**
   - **Execute as: Me**
   - **Who has access: Anyone**
6. กด Deploy → กด Allow เมื่อขึ้นหน้าขอสิทธิ์
7. คัดลอก **Web app URL** ที่ได้

**เมื่อแก้โค้ดในอนาคต:** ต้องกลับไปที่ **Deploy > Manage deployments** → แก้ไข **รายการเดิมที่ URL ตรงกับใน config.js** → เปลี่ยน Version เป็น **New version** → Deploy ทุกครั้ง (แค่กด Save ในหน้า Editor ไม่พอ ลิงก์ที่ใช้งานจริงจะไม่อัปเดตโค้ดตาม)

## ขั้นตอนที่ 2: ตั้งค่า Frontend

เปิดไฟล์ `frontend/config.js` แล้วใส่ค่า 2 ตัว:

```js
const API_URL = 'https://script.google.com/macros/s/xxxxx/exec';
const ACCESS_KEY = 'รหัสลับเดียวกับที่ตั้งใน DASHBOARD_ACCESS_KEY';
```

**ข้อควรรู้เรื่องความปลอดภัย:** รหัสลับนี้ฝังอยู่ในไฟล์ JavaScript ฝั่ง frontend ใครก็ตามที่เปิดดูโค้ดหน้าเว็บ (View Source) จะเห็นได้ เหมาะสำหรับกันคนทั่วไปที่ไม่รู้จักเว็บนี้ ไม่เหมาะกับการป้องกันคนในทีมที่ตั้งใจเอาข้อมูลออกไปจริงจัง — เหมาะกับการใช้งานภายในทีมที่ไว้ใจกัน

## ขั้นตอนที่ 3: อัปโหลดขึ้น GitHub Pages

1. อัปโหลดไฟล์ในโฟลเดอร์ `frontend/` ทั้งหมด (`index.html`, `style.css`, `script.js`, `config.js` ที่ใส่ค่าแล้ว) ไว้ที่ root ของ repo (ทับของเดิม)
2. รอสักครู่ให้ GitHub Pages อัปเดต แล้วเปิดเว็บไซต์แบบ Ctrl+Shift+R เพื่อล้าง cache เก่า

## API ที่ใช้

ทุก action ต้องแนบ `&key=รหัสลับ` เสมอ

| Action | ตัวอย่าง URL | คืนค่า |
|---|---|---|
| รายชื่อไฟล์ทั้งหมด | `?action=books&key=...` | `{ ok, books: [ชื่อไฟล์, ...] }` — เร็วมาก ไม่แตะเนื้อหาในชีต |
| เพิ่มไฟล์ใหม่เข้าระบบ | `?action=addBook&name=ชื่อที่จะแสดง&sheetUrl=ลิงก์หรือID&key=...` | `{ ok, message, books }` — ทดสอบเปิดไฟล์จริงก่อนบันทึกเสมอ |
| เอาไฟล์ออกจากระบบ | `?action=removeBook&name=ชื่อไฟล์&key=...` | `{ ok, message, books }` — ไม่ได้ลบไฟล์ Google Sheet จริง |
| รายชื่อแท็บของไฟล์ | `?action=sheets&book=ชื่อไฟล์&key=...` | `{ ok, sheets: [{book, name, rowCount}], updatedAt }` |
| ข้อมูลทั้งแท็บ (ตารางเดียว) | `?action=sheet&book=ชื่อไฟล์&name=ชื่อแท็บ&key=...` | `{ ok, headers, rows, updatedAt }` |
| ค้นหาในไฟล์ที่ระบุ | `?action=search&q=คำค้นหา&book=ชื่อไฟล์&key=...` | `{ ok, results: [{book, sheet, row, cells}], truncated, updatedAt }` |
| ค้นหาเฉพาะแท็บเดียว | `...&book=ชื่อไฟล์&sheet=ชื่อแท็บ&key=...` | เหมือนด้านบน แต่เจาะจงแท็บ |
| ชื่อคอลัมน์ของแท็บ | `?action=headers&book=ชื่อไฟล์&sheet=ชื่อแท็บ&key=...` | `{ ok, headers: [...] }` |
| เพิ่มแถวข้อมูลใหม่ | `?action=add&book=...&sheet=...&data=<JSON>&key=...` | `{ ok, message, row }` |
| ลบแถวข้อมูล | `?action=deleteRow&book=...&sheet=...&row=เลขแถว&key=...` | `{ ok, message }` — บันทึกสำเนาไว้ในถังขยะก่อนลบเสมอ |
| ลบคอลัมน์ทั้งคอลัมน์ | `?action=deleteColumn&book=...&sheet=...&column=ชื่อคอลัมน์&key=...` | `{ ok, message }` — บันทึกสำเนาไว้ในถังขยะก่อนลบเสมอ |
| ดูรายการในถังขยะ | `?action=trash&book=...&key=...` | `{ ok, items: [{id, deletedAt, type, sheetName, columnName, preview}] }` |
| กู้คืนรายการจากถังขยะ | `?action=restore&book=...&id=...&key=...` | `{ ok, message }` — เพิ่มข้อมูลกลับเข้าชีตจริง (ท้ายชีต) แล้วลบออกจากถังขยะ |

## หมายเหตุ

- แท็บที่อยู่ใน `HIDDEN_SHEETS` (ในโค้ดคือ `'ชีต12'`) จะไม่ถูกดึงมาแสดงหรือค้นหาเลย ใช้ร่วมกันทุกไฟล์ **นอกจากนี้ แท็บที่ถูกซ่อนไว้จริงในตัว Google Sheets เอง (คลิกขวา > ซ่อนชีต) จะไม่ถูกดึงมาแสดงเช่นกัน โดยอัตโนมัติ ไม่ต้องเพิ่มชื่อในโค้ด**
- ฟอร์ม "เพิ่มข้อมูล" จะสร้างช่องกรอกให้เหมาะกับแต่ละคอลัมน์อัตโนมัติ: คอลัมน์ที่ชื่อมีคำว่า "วันที่" หรือ "date" จะได้ปฏิทินเลือกวันที่ ส่วนคอลัมน์ที่ตั้ง Data Validation แบบ "เลือกจากรายการ" ไว้ในชีตอยู่แล้ว จะได้ dropdown ตามตัวเลือกจริงในชีต ไม่ต้องตั้งค่าซ้ำฝั่งเว็บ
- ผลการค้นหาจำกัดไว้ที่ 200 แถวต่อครั้ง แก้ได้ที่ `SEARCH_RESULT_LIMIT`
- มี cache 5 นาที (`CACHE_SECONDS`) แยกตามไฟล์+แท็บ ถ้าแก้/ลบข้อมูลผ่านหน้าเว็บ ระบบจะล้าง cache ของแท็บนั้นให้อัตโนมัติ แต่ถ้าไปแก้ข้อมูลตรงในชีตเองโดยไม่ผ่านเว็บ ต้องรอ cache หมดอายุ
- **การลบแถว/ลบคอลัมน์จะบันทึกสำเนาไว้ในถังขยะก่อนลบเสมอ** กู้คืนได้ผ่านปุ่ม "🗑 ถังขยะ" บนหน้าเว็บ ข้อมูลที่กู้คืนจะถูกเพิ่มกลับเข้าไปท้ายชีตปลายทาง (ตำแหน่งเดิมเป๊ะๆ คืนให้ไม่ได้ ถ้าแถว/คอลัมน์อื่นมีการเปลี่ยนแปลงไปแล้วหลังจากลบ) ถังขยะเก็บประวัติล่าสุดไว้สูงสุด 200 รายการต่อไฟล์ (ตั้งค่าที่ `TRASH_MAX_ENTRIES`) เก่ากว่านั้นจะถูกลบทิ้งถาวรแบบกู้คืนไม่ได้อีก
- ถังขยะเก็บอยู่ในแท็บที่ชื่อ `_Trash` ซึ่งถูกซ่อนอัตโนมัติในแต่ละไฟล์ (สร้างขึ้นเองครั้งแรกที่มีการลบข้อมูล) ไม่ต้องไปยุ่งกับแท็บนี้เอง
- ปุ่ม "จัดการคอลัมน์" จะขึ้นให้กดก็ต่อเมื่อเลือกแท็บใดแท็บหนึ่งแล้วเท่านั้น (เลือก "ทั้งหมดในไฟล์นี้" จะไม่ขึ้น เพราะการลบคอลัมน์ต้องระบุแท็บเดียวชัดเจน)
- เพิ่มไฟล์ใหม่ในอนาคตได้ผ่านปุ่ม "+ เพิ่มไฟล์ใหม่" บนหน้าเว็บโดยตรง ไม่ต้องแก้ไฟล์ `Code.gs` หรือ Deploy ใหม่อีกต่อไป — รายชื่อไฟล์ตอนนี้เก็บอยู่ใน Script Properties ของโปรเจกต์ (key: `SPREADSHEETS_JSON`) ไม่ใช่ค่าคงที่ในโค้ด
- **ข้อควรรู้เรื่องสิทธิ์:** ทุกคนที่มีรหัสเข้าถึง (ACCESS_KEY) สามารถเพิ่ม/เอาไฟล์ออกจากระบบได้ผ่านหน้าเว็บ เหมาะกับทีมที่ไว้ใจกัน — การเพิ่มไฟล์ใหม่จะทดสอบเปิดไฟล์จริงก่อนบันทึกเสมอ (ถ้าบัญชีที่รันสคริปต์นี้ไม่มีสิทธิ์เข้าถึงไฟล์ที่วางลิงก์มา จะเพิ่มไม่สำเร็จ) ส่วนการเอาไฟล์ออกเป็นแค่เอาออกจากรายการที่เว็บนี้รู้จัก ไม่ได้ลบไฟล์ Google Sheet จริงแต่อย่างใด
